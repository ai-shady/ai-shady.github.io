PostHog Cloud vs Amplitude vs Iterable

跨「度量 · 实验 · 客户数据 · 跨渠道触达」的能力对照表。PostHog 侧统一按 PostHog Cloud （官方全托管云版本）口径：横跨分析与消息的一体化平台；Amplitude 是分析侧冠军；Iterable 是消息触达侧冠军。 评分口径：Full 一等公民 / Partial 早期·受限·经合作方 / None 不提供。

Cloud 本文 PostHog 列全部以 PostHog Cloud 为准：官方托管、免运维、自动升级到最新版本， 所有产品（分析、回放、Flags、实验、错误追踪、日志、LLM 观测、数仓、CDP、Workflows 触达） 在云上开箱即用。（PostHog 核心同时开源可自托管，但自托管版本的功能与运维状态不在本文口径内。）

PostHog Cloud

官方全托管云版本，免运维、自动升级。分析、回放、Feature flags、实验、错误追踪、LLM 观测、数仓、CDP，并通过 Workflows 提供原生跨渠道触达。

Amplitude

产品分析领导者，整合会话回放、功能实验、CDP/激活、Guides & Surveys。不做消息投递。

Iterable

跨渠道互动平台。邮件、SMS、Push、In-app、WhatsApp、旅程编排、AI 发送决策。不做产品分析。

选型建议

选 PostHog Cloud 当…

你想用一套官方全托管平台覆盖分析、回放、flags、实验、错误追踪、日志、LLM 观测与数仓，并希望直接基于真实产品事件触发邮件 / SMS / Push，而不想再接一个独立 ESP。免运维、自动升级，最适合工程团队主导的技术栈。

选 Amplitude 当…

严谨的产品分析与高级实验（CUPED、sequential、bandit、holdout）是核心诉求，消息交给专用工具。可与 Iterable 搭配补足发送侧。

选 Iterable 当…

跨渠道生命周期营销、送达率工程与发送时机 AI 是主业。上游可搭配 PostHog Cloud / Amplitude 补足产品分析侧。
